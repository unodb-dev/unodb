Detailed Description

Non-atomic lock word representation.

Used for copying and manipulating snapshots of the atomic lock word. The lock word consists of:

  • Bit 0: obsolete state. If set, all other bits are zero.
  • Bit 1: write lock
  • Bits 2-63: version counter
