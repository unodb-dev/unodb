Detailed Description

template<class Db>
class anonymous_namespace{test_art_upsert.cpp}::seen_values< Db >

The values an upsert lambda saw, one per call.

It lives outside the lambda because upsert copies fn into every attempt, and it copies value_view bytes because a concurrent writer may retire the leaf they point into.
