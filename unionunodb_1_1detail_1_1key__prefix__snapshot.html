Detailed Description

Key prefix bytes and length, copied from a key_prefix in one load.

Exposes a key_view over internal data that was atomically copied from a key_prefix. Direct use of key_prefix is not possible because: (a) its word is rewritten in place while OLC readers may be loading it (an I4 collapse prepends to the surviving inode's prefix, and a prefix split cuts the split node's), so a reader that loads the length and the bytes separately can pair two versions; and (b) key_view is a non-owned view.

auto unodb::detail::key_prefix_snapshot::get_shared_length ( std::uint64_t shifted_key_u64) const
inlinenodiscardconstexprnoexcept

Return the number of leading bytes, at most length(), in which this prefix equals shifted_key_u64.

For a key_view key shorter than length(), the comparison runs into get_u64()'s zero padding. If the key matches up to its end, the count is at least size(), and more when the padding matches zero prefix bytes. Check that the count is below size() before indexing the key at it, and that length() is at most size() before shifting the key by length().
