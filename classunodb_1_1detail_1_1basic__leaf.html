Detailed Description

template<class Key, class Header>
class unodb::detail::basic_leaf< Key, Header >

Leaf node storing key-value pair.

Handles most leaf behavior for the index. Specialized for OLC which includes additional information in the header. The leaf contains a copy of the key and a copy of the value.

Template Parameters
KeyKey type (fixed-width integral or key_view)
HeaderNode header type (varies between plain and OLC variants)
