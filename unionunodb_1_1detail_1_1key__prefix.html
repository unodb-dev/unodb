template<typename ArtKey, template< class > class CriticalSectionPolicy>
union unodb::detail::key_prefix< ArtKey, CriticalSectionPolicy >

Key prefix for prefix compression in internal nodes.

Stores zero or more bytes that are common prefix shared by all children of a node, supporting prefix compression in the index.

inlinenodiscardconstexprnoexcept

Return the number of leading bytes in which this prefix equals shifted_key_u64, with key_prefix_snapshot::get_shared_length()'s caveat about short key_view keys.

The prefix bytes and length() are loaded separately. Under OLC a concurrent prefix rewrite can land between those loads, or between them and a length() the caller loaded, so the count need not match any single prefix state or stay within the caller's length(). A reader that uses the count with a length() must take both from one get_snapshot().

Parameters
shifted_key_u64get_u64() of the key after shift_right() past the matched bytes
Returns
Number of leading bytes in common, at most the length() this call loads
