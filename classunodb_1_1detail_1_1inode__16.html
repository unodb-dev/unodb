Detailed Description

template<typename Key, typename Value, typename HeapTag>
class unodb::detail::inode_16< Key, Value, HeapTag >

Internal node with 16 children for non-thread-safe ART.

Used when inode_4 grows beyond capacity or when inode_48 shrinks below minimum occupancy.
