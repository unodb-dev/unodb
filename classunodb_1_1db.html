Detailed Description

template<typename Key, typename Value, typename HeapTag>
class unodb::db< Key, Value, HeapTag >

A non-thread-safe implementation of the Adaptive Radix Tree (ART).

See also
unodb::olc_db for a highly concurrent thread-safe ART implementation.

detail::node_ptr  child,
detail::tree_depth< art_key_type >  start_depth 
)
private

Build an inode chain for the first key_view insert into an empty tree.

For key_view keys, the tree must always have at least one inode above every leaf so that the iterator's key buffer (keybuf_) is populated during traversal. This method wraps child in a chain of single-child I4 nodes, each consuming up to key_prefix_capacity prefix bytes + 1 dispatch byte from the key. Built bottom-up: the last I4 created (with prefix from the start of the key) becomes the root.

Parameters
kThe full encoded key
childThe node to place at the bottom of the chain
start_depthDepth at which the chain starts (default 0)
Returns
The chain top node, or child if no bytes to encode

◆ scan_range()

Key  to_key,
FN  fn 
)

Scan a half-open key range, applying the caller's lambda to each visited leaf.

The scan will proceed in lexicographic order iff from_key is less than to_key and in reverse lexicographic order iff to_key is less than from_key. When from_key < to_key, the scan will visit all index entries in the half-open range [from_key,to_key) in forward order. Otherwise the scan will visit all index entries in the half-open range (from_key,to_key] in reverse order.

Parameters
from_keyis an inclusive bound for the starting point of the scan.
to_keyis an exclusive bound for the ending point of the scan.
fnA function f(unodb::visitor<unodb::db::iterator>&) returning bool. The traversal will halt if the function returns true.
