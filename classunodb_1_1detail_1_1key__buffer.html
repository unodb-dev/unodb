Detailed Description

Expandable buffer for binary comparable keys.

Used to track key by iterator as things are pushed and popped on the stack.

◆ assign_from()

void unodb::detail::key_buffer::assign_from ( const key_buffer & src)
inline

Replace the contents with a copy of those of src.

Contents of up to detail::INITIAL_BUFFER_CAPACITY bytes are copied in whole chunks of a fixed size, which compile to a few moves where a copy of variable size is a call: an OLC iterator makes this copy on every step. The last chunk may copy bytes past the end of the contents, but not past the end of either buffer, whose capacity is never below that size.
