anonymous_namespace{test_art.cpp}::UNODB_TEST ( InterceptedFailureGuard ,
ClearsAndRestoresFlags  )

intercepted_failure_guard clears both flags for its lifetime and then restores each from its own saved value.

Each flag is set alone, as the test_art_intercepted_failure_* reruns set them, so that a guard that restores a flag from the other's value fails too. The flags are restored before anything is asserted, so that a broken guard fails this test instead of trapping or throwing in it.
